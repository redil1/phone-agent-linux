Speech-to-Speech (S2S) streams PCM audio directly to OpenAI's Realtime model over a server-to-server WebSocket, bypassing a separate STT → LLM → TTS chain.
S2S Realtime Features:
  • Stateful 16 kHz ↔ 24 kHz PCM resampling with no Opus/RTP round trip
  • Deterministic 450 ms server VAD creates responses; transcription never gates speech
  • Automatic WebSocket recovery prevents prolonged silence after a network drop
  • Android render acknowledgements drive exact barge-in truncation
  • Clean-call persona and task context with no caller or account memory
