The STT executor is genuinely Faster-Whisper `large-v3-turbo`. Its buffered telephone wrapper is
misleadingly named `ParakeetLocalSTTService` and emits `source=local_parakeet`; source construction,
model prewarm, runtime start, and weight cache all prove the selected Whisper model. This is an
observability naming defect to remove, not evidence that WebUI model selection failed.

Speculative mode was configured on, but runtime rejected speculation for this provider combination
and used the normal authoritative-turn path. The report records desired and effective state
separately.

`com.phoneagent.gateway` version `1.0.0` was installed as an updated privileged system application,
enabled, not stopped, and holding the dialer role. The update APK and baked system APK differ, so a
normal reboot retains the update, while uninstalling updates or a factory reset can revert to the
older baked artifact. Verified boot was `orange`; this is a qualification device, not a locked
consumer-production image.
