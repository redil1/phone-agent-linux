## 2. Deliverables & Technical Enforcements

1. **Versioned Runtime Schema (`M2-01`):**
   - Implemented `UniversalRuntimeConfigSchema` in `ai_bridge/runtime_schema.py` strictly enforcing fields for STT, LLM, TTS, turn detection, audio parameters, deployment profiles, active package identity, and allowed tools.
2. **Precedence & Provenance (`M2-02`):**
   - `compile_effective_configuration` implements unambiguous hierarchical precedence:
     `Active Agent Package` > `Environment Variables` > `Studio Stored Settings` > `System Defaults`.
   - Records field-level origin in `source_provenance`.
3. **Compile-Before-Save Validation (`M2-03`):**
   - `validate_compiled_configuration` validates model/provider/voice combinations and context limits before saving.
4. **Transactional Activation (`M2-04`):**
   - `TransactionalControlPlane.activate` requires non-active call state, validates and prewarms, activating at call boundaries and automatically rolling back on failure.
5. **Authoritative Read-Back (`M2-05`):**
   - `read_back()` reports desired, staged, active, and worker state with SHA-256 state hashes and sync status.
6. **Configuration Audit Ledger (`M2-06`):**
   - `ConfigurationLedgerRecord` creates signed, append-only, local audit records of every stage, activation, and rollback action.
7. **Control Plane Security (`M2-07`):**
   - Verified loopback-only binding enforcement (`127.0.0.1`, `localhost`, `::1`) and cryptographic token authentication.
8. **Regression Test Suite (`M2-08`):**
   - `tests/test_runtime_schema.py` provides full round-trip, validation failure, mid-call safety, and audit coverage.
