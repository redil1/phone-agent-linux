# M0-05 — Reproducible CI stages

Date: 2026-09-02 UTC

## Outcome

PhoneAgent now has one executable CI contract shared by developers and GitHub Actions. Ten
independently observable jobs cover quality, fast unit tests, integration tests, Python packaging,
Android APK/protocol compatibility, dependency security, licence/SBOM evidence, the CUDA container,
deterministic conversation evaluations, and opt-in device qualification.

The hosted workflow is `.github/workflows/ci.yml`; every job delegates its product-specific work to
`ci/run-stage.sh`. This prevents hosted CI and local validation from silently diverging.

## Safety and supply-chain controls

- Workflow token permissions are read-only.
- Every external action reference is pinned to a full 40-character commit:
  `actions/checkout` v6.0.2, `astral-sh/setup-uv` v9.0.0, `actions/setup-java` v5.6.0, and
  `actions/upload-artifact` v7.0.1. The refs were checked against the authoritative GitHub
  repositories with `git ls-remote` on 2026-09-02.
- uv is pinned to 0.12.9 in the workflow; Pytest 8.4.2, pytest-asyncio 1.2.0, Ruff 0.12.12, and
  Pyright 1.1.411 are exact development dependencies in `uv.lock`.
- Device qualification is absent from push and pull-request execution. It requires a manual boolean
  input, a protected `device-qualification` environment, a labelled self-hosted runner, and the
  explicit `PHONE_AGENT_DEVICE_CI=1` process gate. The stage qualifies only; it never places a call.
- Pull requests perform the production Dockerfile check. Main-branch and manual runs additionally
  build the complete CUDA image.
- The security validator rejects new advisories, package/version drift, expired exceptions, missing
  ownership, or stale exceptions.

## Defects found while proving the stages

1. `uv sync --dev` did not install the existing `dev` optional extra. CI now uses
   `uv sync --locked --extra dev`; the all-extras licence job is explicit.
2. Ruff's configured `exclude` replaced its default `.venv` exclusions. It is now
   `extend-exclude`, and the proven Ruff version is pinned.
3. Android protocol scripts hard-coded one Mac SDK path. They now accept `ANDROID_HOME`,
   `ANDROID_SDK_ROOT`, or `PHONE_AGENT_ANDROID_JAR` and fail with a clear message.
4. The Android build inherited Java 21 bytecode, which API-34 D8 rejected. APK and interop compiles
   now enforce `javac --release 17`; the workflow installs Temurin 17.
5. The unsigned release script failed immediately outside Git even though this project was
   intentionally reset. Unsigned local builds now work without revision metadata; signed releases
   still require an initialized, clean repository.

## Explicit governance debt carried to M0-07

`pip-audit` reports `PYSEC-2026-3740` / `CVE-2026-81726` in transitive `nltk==3.10.3`, for which no
fixed release was available. PhoneAgent does not expose the affected NLTK model-path APIs. The
exception is owned, exact-version-bound, and expires on 2026-12-01. CI will fail if it expires or
becomes stale.

The licence inventory reports unknown metadata for `cuda-toolkit`, `espeakng-loader`,
`google-crc32c`, `kaldiio`, and the PhoneAgent project itself. M0-07 must resolve and approve these;
the inventory makes the debt visible but M0-05 does not pretend the commercial licence review is
complete.
